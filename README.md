# 타자 스태커

[![CI](https://github.com/SeongYongLee/typing-stacker/actions/workflows/ci.yml/badge.svg)](https://github.com/SeongYongLee/typing-stacker/actions/workflows/ci.yml)

**▶ 플레이: https://typelostfound.quest/** (데스크톱 · 물리 키보드)

한글 타자게임과 물리 쌓기를 합친 웹 게임. 좌우에서 내려오는 단어를 타이핑하면, 그 단어에 해당하는 물건이 가운데 받침대 위로 떨어져 쌓인다.

**핵심 규칙은 Enter 하나다.** Enter를 누른 순간 입력이 확정되고, 그 순간의 조준 화살표 위치로 물건이 곧바로 떨어진다. 그래서 "단어가 바닥에 닿기 전에 빨리 쳐야 한다"와 "원하는 위치에 떨구려면 타이핑 완료 시점을 맞춰야 한다"가 정면으로 충돌한다. 어떤 물건이 나올지는 Enter를 누른 뒤에야 알 수 있고, 낮은 확률로 모양이 다른 **히든** 변형이 나온다.

싱글은 테마가 다른 다섯 보관함을 차례로 연다. 화이트보드에 적힌 물건이 상자 안에 있을 때 단어를 입력하면 그 물건을 회수할 수 있고, 스테이지별 목표 횟수를 채우면 다음 보관함으로 넘어간다. 마지막 보관함을 마치면 엔딩이 열리고, 같은 상자와 탑에서 목표 없이 계속 정리할 수도 있다.

**싱글에서 물건 하나가 상자 밖으로 떨어지면 바로 게임오버다.** 고양이가 떨어진 물건을 물고 가는 동안 무너지는 장면을 보여준 뒤 결과 화면으로 넘어간다. 화이트보드 회수로 빠져나간 물건은 게임오버 판정에서 제외한다.

**단어를 놓치면 혼잡 경보가 20%씩 찬다.** 정상 입력은 경보를 2% 낮추며, 게이지가 줄어드는 동안 테두리가 초록색으로 반응한다. 100%가 되면 현재 보관함의 물건 10~22개가 0.5초 간격으로 자동 반입되어 상자가 급격히 비좁아진다. 잘못 입력한 단어는 경보가 아니라 정확도와 점수에 반영된다.

**난이도는 스테이지를 따라 오른다.** 1단계의 생성 간격·낙하 시간은 2초·8초이고 마지막 단계에서는 1.5초·6초가 된다. 동시에 상자 폭은 좁아지고 혼잡 경보 반입량은 늘어난다. 세부 수치와 튜토리얼 흐름은 [싱글 플레이 문서](docs/SINGLEPLAYER.md)에 정리되어 있다.

## 합성

**재료 둘이 서로 닿으면 합쳐져 새 물건이 된다.** 같은 물건 둘을 합치면 그 물건의 히든이 되고(피자 조각 둘 → 피자 한 판), 서로 다른 물건을 합치면 **합성으로만 나오는 물건**이 된다(계란 + 프라이팬 → 계란 프라이). 뒤쪽은 타이핑으로는 절대 떨어지지 않아서 도감에서 "손으로만 채우는 칸"이 된다.

**합성의 보상은 판 안의 자리가 아니라 판 밖에 남는 것이다.** 도감의 빈 칸이 채워지고, 그 히든을 봤다는 사실이 남고, 프로필 사진으로 쓸 수 있다. 한때는 "결과물이 재료보다 좁아야 한다"는 규칙이 있었지만, 물건마다 크기가 다른 것이 이 게임의 컨셉이라 아트가 정한 크기 쪽이 이겼다.

**합성하면 공중에 작은 통나무가 하나 선다.** 판을 끝내는 것은 점수가 아니라 얹을 자리가 좁아지는 것이라, 자리를 하나 더 주는 것이 이 게임의 말로 된 보상이다. 받침대 밖에 서므로 없던 자리가 열리고, 옆으로 흘러내리던 물건도 거기서 걸린다. 운으로 만난 히든에는 주지 않는다 — 아무것도 하지 않아도 나오는 것에 같은 것을 주면 판을 여는 자리가 실력이 아니라 운으로 갈린다.

판 앞머리에는 쉽게 합쳐지는 몇 단어만 내려온다. 좁히기 전에는 25번을 떨궈도 40판 중 7판만 첫 합성에 닿았다 — 만들어놓고 거의 아무도 못 보는 기능이었다.

## 그 밖에

- **도감** — 물건 전부를 담는다. 못 찾은 칸은 실루엣으로 두어 "무엇이 남았는지"가 보인다
- **전역 순위** — 판이 끝나면 기록을 보내고 순위를 받는다. 판이 도는 동안 화면 위에 지금 몇 위인지와 무엇을 쫓고 있는지가 한 줄로 뜬다
- **소리** — 오디오 파일이 하나도 없다. 전부 WebAudio로 합성한다. 부딪힌 세기가 곧 음량이고 물건의 크기가 곧 음높이다
- **멀티 대결** — 각자 쌓고 합성 공격을 주고받는 개인 생존전. 중계 서버를 거쳐 붙는다

## 실행

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

데스크톱 가로 화면 + 물리 키보드 전용이다. 타자게임이므로 모바일은 지원하지 않는다.

`main`에 푸시하면 GitHub Actions가 typecheck·테스트를 돌린 뒤 GitHub Pages로 배포한다. 프로덕션 빌드는 상대 `base`를 사용해 커스텀 도메인 루트와 기존 `/typing-stacker/` 경로를 모두 지원하고, 런타임에서 만드는 스프라이트 경로는 `import.meta.env.BASE_URL`을 앞에 붙인다 — 로컬 개발 서버는 계속 루트로 뜬다. 커밋 전에는 pre-commit 훅이 **커밋될 내용만 임시로 꺼내** typecheck·lint·테스트를 돌린다. 워킹 트리가 어수선해도 올라가는 것 자체는 온전하다.
