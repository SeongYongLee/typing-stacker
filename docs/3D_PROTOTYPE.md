# 깊이 고정 3D 프로토타입

2026-09-07 · 현재 기본 방향은 **원래 2D 물건 + 3D 상자·그림자·이펙트 + 작은 젤리 반응**이다.

## 실행

```sh
pnpm install
pnpm dev --host 127.0.0.1 --port 5183 --strictPort
```

시험장은 개발 서버에서만 열린다. 일반 싱글플레이·튜토리얼도 원래 2D 물건과 3D 상자·빛·연출을 사용한다. Three.js는 게임 진입 시 지연 로드하며 그래픽 연결이 끊기면 같은 판을 유지한 채 2D로 복귀한다.

- `물건 비교`: 대표 6종을 같은 위치에서 기본 조합(2D 물건 + 3D 상자) / 기존 2D / 이전 입체 실험으로 비교한다.
- `튜토리얼 플레이`: 기존 책 → 계란 → 프라이팬 → 합성 → 화이트보드 회수 → 경보·게임오버 흐름을 플레이한다.
- `싱글 새로 시작`: 기존 1~5단계 규칙으로 시작한다.
- 표현 전환은 진행 중인 엔진과 물리 세계를 유지한다. 일시정지 상태에서도 전환할 수 있다.
- `옆면 보기 8°`: 카메라를 좌우 방향으로만 조금 돌린다. 깊이 조준·물체 깊이 이동은 없다.
- `충돌 윤곽`: 실제 충돌 조각을 초록색으로 겹쳐 그린다. 접촉 비교를 위해 카메라를 정면으로 고정한다.
- `밤 조명`: 그림의 조명만 바꾸는 비교 기능이다. 게임 시간·단어 속도는 바꾸지 않는다.

이 실험은 도감 저장과 랭킹 연결을 하지 않는다. 다시 시작하면 시드 `20260907`을 사용한다. 시드가 같아도 사람이 입력한 시점이 다르면 물리 결과는 다를 수 있다.

## 범위와 시각적 선택

물리는 Rapier2D 그대로이며 게임 물건 중심의 Z는 0, 물리 회전은 Z축 하나다. 장식 입자와 회수 연출에는 시각적인 Z 이동이 있다. Three.js는 같은 `BodySnapshot`의 X/Y/rotation을 받아 그리기만 한다. DOM 한글 입력·낙하 단어·화이트보드를 그대로 사용한다.

이전 입체 비교 모드의 대표 6종은 책(`study-book`), 계란, 프라이팬, 축구공, 우산, 계란 프라이다. 기존 스프라이트의 외곽선을 유지하고 실제 정점 깊이를 다르게 준 **텍스처 기반 부조 모델**이다. 완성된 독립 3D 모델이나 새로 모델링한 소품은 아니다. 이 단계의 목적은 충돌 모양을 지키면서 부피·그림자·시점의 효과를 비교하는 것이다. 다른 물건은 같은 윤곽을 돌출시킨 두꺼운 스티커로 나타난다.

상자는 Three.js 메시와 그림자를 사용한다. 낙하·착지 입자, 충격 고리, 합성 고리·조명, 발판 생성과 회수 궤적은 Three.js에서 그린다. 합성 재료·결과 그림과 글자, 조준·짝 표식, 손·고양이는 Canvas 오버레이에 유지한다. 전환 도중 이미 진행 중인 부스러기의 과거 위치까지 복원하지는 않는다. 싱글의 카메라 높이는 현재 엔진이 주는 값을 그대로 따르며, 카메라 추적 규칙은 변경하지 않았다.

## 구조와 수명 관리

- `ArenaRendererPort`: 엔진이 소유하는 draw/resize/dispose 계약.
- `GameEngine.attachRenderer`: 교체 시 이전 렌더러 자원 해제. Canvas 진입점도 같은 경로를 사용한다.
- `three/projection.ts`: 기존 Canvas와 같은 월드 좌표·프레이밍.
- `three/itemGeometry.ts`: 원본의 outlines로 측면과 앞면 생성. 볼륨은 XY 윤곽을 늘리지 않고 Z만 조정한다.
- `three/ItemAssets.ts`: 변형별 도형·텍스처 공유, 물체별 재질 해제.
- `three/Arena3DRenderer.ts`: 직교 카메라, 조명, 상자, 물체, 그림자, GPU 자원 관리.
- `three/PrototypeOverlay.ts`: 읽을 정보·원본 캐릭터 아트·진단 윤곽 표시.
- `three/Effects3D.ts`, `SpatialParticles.ts`: 게임과 독립된 난수·시간 기반 입체 연출, 제한된 입자 풀과 공유 GPU 도형.
- `dev/ThreePrototype.tsx`: 독립 엔진 세션과 비교 화면. 일반 화면으로 돌아가면 엔진을 해제한다.

React StrictMode는 같은 canvas에서 효과를 다시 실행한다. dispose 직후 컨텍스트를 무조건 잃게 하면 다음 생성에서 실패하므로, GPU 자원은 즉시 해제하고 실제 DOM에서 분리된 canvas에만 컨텍스트 해제를 요청한다.

원래 게임의 `RunChase`는 마운트 때 순위 서비스를 조회하므로, 실험실에서는 `showRanking=false`로 렌더링하지 않는다.

## 현재 방향 검토

사용자 결정: 물건의 2D 그림과 그림자 효과를 유지하고, 3D는 주변 요소에 집중한다. 기존 185종의 식별성과 아트 분위기를 지키며 물건별 3D 모델 제작도 피할 수 있어 이 게임에 적합하다.

| 요소 | 방향 | 이유 |
|---|---|---|
| 물건 | 원본 2D 텍스처·색, 두께 0 | 글자와 물건을 빠르게 연결하고 현재 실루엣을 보존 |
| 물건 그림자 | 실제 알파 실루엣으로 상자에 투영 | 종이가 공간 안에 존재하는 느낌을 연결 |
| 상자·받침대·발판 | 3D 유지 | 모서리·깊이·받치는 면을 읽기 쉽게 표현 |
| 배경 선반·벽·바닥 | 후속 후보: 단순 입체 구조에 기존 아트 사용 | 큰 면과 공간의 깊이에 집중하면 제작 범위를 줄일 수 있음 |
| 글자·화이트보드 내용·입력 | 2D 유지 | 가독성과 한글 입력을 우선 |
| 손·고양이 | 현재 2D 연출 유지, 이후 필요성 평가 | 표정과 동작이 중요한 자산이므로 입체화보다 기존 분위기를 우선 |

젤리는 물리 충돌 이벤트에 반응하는 짧은 화면 변형이다. 그림에 깊이·새 재질을 추가하지 않고, 충돌체와 판정도 바꾸지 않는다. 재질별 반응을 다르게 주고 강도 0~100% 및 끄기를 제공한다. 충돌 윤곽 비교와 동작 줄이기 환경에서는 변형을 끈다. 강도 슬라이더는 물리 세계나 GPU 렌더러를 다시 만들지 않는다.

기본 평면 그림은 MeshBasicMaterial로 조명에 원래 색이 변하지 않게 하고, alphaTest로 투명 사각형이 그림자로 생기는 것을 막는다. 깊이 0인 텍스처 평면은 그림자를 드리우는 데만 3D 렌더러를 사용하며, 물건을 입체 모델로 만드는 방식은 아니다.

## 물건 비교에서 낙하 실험

대표 물건 버튼을 누르면 선택한 좌우 위치에서 하나씩 떨어진다. `6종 모두 떨어뜨리기`는 상자를 비우고 6종을 동시에 떨어뜨린다. `낙하 멈춤/계속`, `상자 비우기`, `비교 배치로 복원`으로 반복 비교할 수 있다. 표현을 전환해도 쌓인 물건과 정지 상태는 유지한다.

`dev/GallerySimulation.ts`는 싱글과 독립된 Rapier2D 세계와 루프를 소유한다. 합성·게임오버 없이 최대 60개를 담는다. 화면에서 벗어나면 루프를 멈추고, 복귀하면 같은 상태로 재개한다.

추가 검증: GallerySimulation 테스트 2개 통과(낙하·착지·초기화·정지·렌더러 교체·재개). 브라우저에서 6종 낙하 → 멈춤 → 두꺼운 스티커 전환 → 비우기 → 개별 낙하 → 비교 배치 복원, 싱글과의 상태 분리를 확인했다. 빌드 통과, 린트 오류 0(기존 경고 2개).

추가 확인: Jelly/평면 아트 테스트와 GallerySimulation/렌더러 테스트 총 7개 통과, 빌드 통과. 브라우저에서 충돌 후 변형(기본 강도에서 최대 약 2.4%), 끄기, 슬라이더 변경 시 동일 canvas 유지, 원본 아트와 실루엣 그림자를 확인했다.


## 3D 이펙트와 반입 시험장 UI

2026-09-07 추가 구현. 기본 물건은 원본 평면 그림과 그림자를 유지한다.

- 낙하·충돌: 실제 X/Y/Z 속도를 갖는 회전 조각과 비스듬한 충격 고리. 최대 입자 240개, 충격 고리 12개로 제한한다.
- 합성: 서로 다른 축으로 도는 입체 고리와 짧은 주변 조명. 재료·결과 그림과 이름은 읽기 쉽게 2D로 남긴다.
- 회수: 원본 그림이 공간 안의 호를 따라 이동하고 작은 입체 조각이 경로를 보여준다. 손 그림은 기존 아트다.
- 발판 생성: 입체 블록이 회전하며 제자리로 이동한다.
- 동작 줄이기: 장식 입자·회전 고리·순간 조명을 끈다. 회수와 합성 결과 정보는 유지한다.
- 비교 화면: `합성 이펙트`, `회수 이펙트`로 3초 미리보기. 실제 합성이나 회수 판정은 발생하지 않으며 물건 목록을 바꾸지 않는다. 일시정지는 미리보기도 멈춘다.

UI는 종이 반입 대장, 붉은 취급 주의 도장, 기존 손그림 배경과 손글씨 서체로 구성했다. 물건은 목록에서 바로 반입하고, 렌더러·조명·윤곽·젤리·GPU 수치는 `화면 설정`에 접어 두었다. 이번 UI 변경 범위는 격리된 프로토타입의 공통 도구와 물건 비교 화면이다. 원래 로비·입력창 전체 재설계는 포함하지 않는다.

최신 검증: 전체 109파일 / 834개 테스트 통과, 프로덕션 빌드 통과, 린트 오류 0(기존 Fast Refresh 경고 2개). Chrome에서 표현 4회 반복 전환, 낙하 입자, 합성·회수 미리보기, 실제 튜토리얼 합성·회수·경보·게임오버·재시작이 통과했다. 브라우저 오류와 외부 요청은 0건. 1440×1000 경보 7초 표본은 가시 물건 최대 80개, 프레임 중앙값 16.7ms / p95 16.8ms였다. 390px 화면의 가로 넘침도 없다.

스크린샷: `artifacts/three-prototype/workbench.png`, `workbench-mobile.png`, `effect-impact.png`, `effect-merge.png`, `effect-recall.png`. 자동화 기록은 같은 폴더의 `checks.json`에 있다.


## 물건에 맞는 3D 이펙트

공통 조각을 `three/ItemEffects.ts`의 시각 프로필로 교체했다. 색뿐 아니라 입체 도형, 속도, 중력, 공기 저항, 흔들림, 수명과 충격 고리 크기를 다르게 쓴다.

| 대표 물건 | 연출 |
|---|---|
| 책 | 얇은 종잇장이 회전하고 좌우로 팔랑임 |
| 계란 | 크림색의 둥근 입자가 부드럽게 퍼짐 |
| 프라이팬 | 길쭉한 금속 불꽃과 작고 빠른 울림 고리 |
| 축구공 | 먼지와 넓게 퍼지는 충격 고리 |
| 우산 | 둥근 물방울이 사방으로 튀고 중력으로 떨어짐 |
| 계란 프라이 | 휘어진 김이 천천히 위로 피어남 |

대표 6종과 우유 2종에는 개별 프로필을 지정했다. 나머지는 10개 재질 분류에 맞는 기본 프로필을 사용한다. 185종 각각에 별도 연출을 제작한 것은 아니다. 소리용 재질 분류와 실제 시각 재료는 다를 수 있어 개별 예외를 먼저 적용한다. 실제 물건의 그림·충돌·합성 판정은 그대로다.

낙하 궤적과 착지에 같은 프로필을 사용한다. 합성 공개 입자는 결과물 프로필을, 회수 궤적 조각은 회수물의 도형과 색을 사용한다. 최대 활성 입자 수 240개와 충격 고리 12개를 유지하고, 6종 공유 도형의 InstancedMesh를 재사용한다. 이전 프레임과 같은 시각에는 입자를 중복 생성하지 않는다.

반입 대장에서 선택한 물건을 표시하고, 화면 오른쪽 아래에 해당 효과의 이름을 보여준다. `node scripts/check-item-effects.mjs`는 대표 6종의 실제 착지·입자 종류, 반복 낙하 후 GPU 자원 수, 동작 줄이기 설정을 확인한다. 결과와 스크린샷은 `artifacts/three-prototype/item-effects/`에 저장한다.

관련 테스트 12개 통과: 6종 효과 구분, 전체 물건 프로필 유효성, 낙하 궤적 프로필, 입자 수 제한·정지·재시작·수명, 비교 세계와 렌더러 격리. 브라우저의 6종 착지 검사와 GPU 자원 반복 검사는 통과했고 오류는 0건이었다.


## 효과와 비교 목록 확장

12개 시각 물건군에 93종을 지정했다. 기존 개별 설정 8종과 중복되지 않아 총 101종이 시각 전용 설정을 사용한다. 나머지 84종은 재질 기본값을 사용한다. 각 물건마다 101개의 독립 효과를 만든 것이 아니라, 특징에 맞는 시각 프로필을 공유하는 구조다.

새 물건군은 꽃과 풀, 나뭇잎, 가을 잎, 빵과 과자, 따뜻한 음식, 차가운 음료, 눈과 얼음, 별과 마법, 전자기기, 비누와 청소, 옷과 털, 바람과 비행이다. 기존 6종 입체 도형에 꽃잎·별·비눗방울·픽셀 4종을 더했다. 최대 활성 입자 240개를 유지한다.

반입 대장에서 전체 185종을 검색하거나 물건군을 선택할 수 있다. 검색은 현재 분류 안에서 이름과 ID를 대상으로 한다. 목록 버튼은 첫 최대 6종을 함께 떨어뜨리고, 결과가 없으면 비활성화된다. 회수 미리보기는 선택한 물건을 사용한다. 합성 미리보기는 계란+프라이팬 예제를 유지하며 화면에도 구분해서 안내한다. 검색과 분류 변경은 canvas나 물리 세계를 다시 만들지 않는다.

관련 테스트 12개 통과(프로필, 전체 ID 유효성, 중복 방지, 무효 입력 무시, 최대 6종 배치, 선택 물건 회수, 기존 185종 도형 검사 포함). 빌드와 린트 통과(기존 경고 2개). 새 4종 입체 도형을 실제 낙하로 확인했고, 전체 185종 목록·검색 결과 없음·분류 배치·canvas 유지·390px 가로 넘침 없음도 브라우저에서 확인했다. 기존 튜토리얼 합성·회수·경보·게임오버·재시작과 반복 표현 전환이 통과했고 브라우저 오류·외부 요청은 0건이었다.

### 창문 빛

3D 모드에서는 기존 CSS 창문 효과를 끄고 Three.js 광선 메시 3개, 먼지 48개, 부드러운 빛 번짐과 SpotLight를 사용한다. 원본 배경의 cover/bottom 배치와 캔버스의 위치 차이를 역투영해 창문에 맞춘다. 카메라 이동에도 광원은 방에 고정된다. 낮에는 따뜻한 색, 밤에는 푸른색으로 전환하며 reduced-motion에서는 먼지와 밝기 변화를 멈춘다. 2D 모드는 기존 CSS 효과를 유지한다. 광선은 부드러운 투명 메시 표현이며, 광선 내부의 체적 그림자를 계산하는 레이마칭 방식은 아니다.

창문 광선은 창가에서 좁고 방 안쪽으로 넓어지며 흐려진다. 먼지는 48개를 유지하면서 세 깊이층으로 나누어 가까운 입자의 크기·이동 속도·흔들림을 키운다. 이동 경로 양끝에서 서서히 나타나고 사라져 순환 시 튀지 않게 한다.

### 합성 연출 조정

합성 안내 위치에서 0.15초 모이기, 0.1초 원본 그림 교체, 0.25초 눌림 복원으로 짧게 조립한다. 이후 결과물과 이름은 기존 안내 시간 동안 유지한다. 세 회전 고리와 합성 발광을 제거하고 작은 접점 선 3개, 먼지 3개와 의미 프로필을 따른 결과 입자 3개를 한 번만 낸다. 원본 2D 그림을 Three.js 평면으로 표시해 입자와 앞뒤로 겹친다. 실제 물리 합성 위치나 판정은 변경하지 않는다. reduced-motion에서는 움직임과 입자 없이 결과만 표시한다.

합성 재료를 0.55초 그대로 보여준 뒤 기존 0.5초 동작을 시작한다. 접점 입자도 0.7초에 맞춘다. 회수 손은 WebGL 물건보다 뒤의 전용 Canvas 층에 그려 원본 물건과 회수 중인 물건을 가리지 않으며, 같은 화면 흔들림·확대 변환을 적용한다.

4개는 2×2, 5개는 3+2로 재료를 표시하고 1초 동안 보여준다. 이름은 두 번째 줄 아래로 내렸다. 합성 안내의 위치는 화면 높이 기준으로 고정하며 카메라 상승을 역보정한다. 안내 그림과 이름은 상자의 흔들림·붕괴 확대를 따라 움직이지 않는다. 비교 화면의 4개/5개 합성 버튼으로 실제 레시피를 재생할 수 있다.

4개 이상 합성은 재료가 순차적으로 모이고 부채꼴 입자와 결과물 크기·그림자 반응을 강조한다. 5개는 0.18초 간격으로 두 번 확산하며 모션 감소에서는 정지 결과만 보여준다. 회수 물건은 퇴장 구간에서 손과 같은 화면 이동량을 적용해 좌우 어느 손이든 함께 빠져나간다.

회수 손 전용 캔버스의 합성된 알파 윤곽에 오른쪽 아래 방향 drop-shadow를 적용한다. 등장·퇴장에는 넓고 연하고, 손이 머무는 구간에는 좁고 진하다. 밤에는 조금 약해진다. 손의 이동과 투명도를 그대로 따르며 실제 3D 표면 투영 그림자는 아니다.

### 큰 합성 유예

작은 레시피에 큰 레시피의 추가 재료가 직접 연결된 경우 1초의 고정 유예를 둔다. 이미 완성된 큰 레시피는 즉시 우선한다. 추가 재료가 떨어지거나 기한이 끝나면 작은 합성을 실행하고, 작은 재료끼리의 연결이 끊기면 취소한다. 독립된 다른 합성은 진행 가능하다. 기다리는 실제 물건의 윤곽과 접촉 점선을 표시하며, 모션 감소에서는 고정 밝기로 표시한다. 일시정지는 타이머를 멈추고 재시작은 초기화한다. 실제 충돌 레시피는 행운의 화분, 마법책, 우주 포스터다.

### 혼잡 경보

3D 모드에서 화면 전체의 붉은 테두리와 낙하 상자 아이콘을 끄고, 실제 상자 테두리에 주황빛 맥동을 적용한다. 경보 진입 때 모서리 먼지 8개가 짧게 떨어진다. 80%부터 경보가 시작되고 위험도에 따라 맥동과 작은 삐걱 소리 간격이 짧아진다(최소 1.2초). 소리는 기존 효과음 버스·음소거 설정을 따른다. 회수로 경보가 해소되면 빛은 감쇠하고 추가 소리는 멈춘다. 게이지의 혼잡 도장은 크기 변화 없이 밝기만 변하며 모션 감소에서는 정지한다. 물건·입력 글자는 경보로 변형하지 않는다.

## 실제 게임 적용과 연속 합성

데스크톱·모바일 싱글플레이는 `GameArena`가 렌더러를 관리한다. 합성은 즉시 물리·점수에 반영하고 `MergeRevealQueue`에 연출을 순서대로 보관한다. 재료와 결과를 읽을 시간을 유지하며 현재 연출이 끝나야 다음 연출을 시작한다. 일시정지 중에는 진행하지 않고 새 판에서 대기열을 비운다.
