# 물건과 효과의 의미 검증

2026-09-07 · 원본 아트 검토에 기반한 디자인 기준. 자동 검사는 이 기준과 실제 방출 결과의 일치를 확인하며, 의미를 독립적으로 이해하거나 사용자 취향을 보증하는 검사는 아니다.

## 검증 방식

- 전체 185종의 원본 그림·이름을 검토하고 허용 도형·색·낙하 방출 여부를 `tests/fixtures/item-effect-meaning.json`에 고정했다. 구현의 그룹 테이블을 테스트 실행 중 복사하지 않는다.
- `ItemEffectMeaning.test.ts`는 설정뿐 아니라 실제 착지 입자와 낙하 입자의 도형·색·유무를 검사한다. 새 물건에 검토 항목이 없거나 중복되면 실패한다.
- 바람은 네 방향 이동에서 입자 위치와 속도가 이동 뒤편인지 확인한다. 소화기·거북이·밀폐 용기 접촉 효과는 본체 하단에서 시작하는지 검사한다.
- 현재 엔진에는 물건 사용 상태가 없다. 가전제품 작동·소화기 분사·밀폐 용기 누수를 자동으로 가정하지 않는다. 김·별빛·불 켜진 촛불·기체처럼 아트가 보여주는 지속 효과만 낙하 중 허용한다.
- 접촉 효과의 하단 위치는 회전한 아트 경계로 추정한다. 실제 Rapier 접촉점에 연결한 것은 아니다.

## 주요 수정

거북이의 나무 먼지, 소화기의 불꽃, 클로버·벼의 분홍 꽃잎, 선인장의 넓은 잎, 문어소시지와 소시지의 불일치, 디저트 타워의 유리 효과를 수정했다. 방귀 기체·마법문·촛불은 아트 색과 모양을 반영했다. 밀폐 용기는 접촉 파문으로, 작동 상태가 없는 가전은 착지 효과로 제한했다. 음향 기기에는 고리, 눈에는 6갈래 결정, 하트에는 하트 도형을 사용한다.

기존 재질 분류는 소리용이므로 검토한 물건별 예외가 우선한다. 분류 메뉴는 탐색용이며, 그 안의 모든 물건이 같은 효과를 사용하는 것은 아니다.

## 새 효과 속성

이펙트 종류는 총 19개다. 새로 분리한 종류는 곡물과 씨앗, 빛과 조명, 소리와 진동, 연기와 기체, 흙과 모래, 추진과 부양, 보석과 반사광이다. 가전은 따뜻한 음식에서 제외하고, 우주선은 전자기기에서, 반사광 소품은 마법에서 분리했다.

| 속성 | 값과 적용 |
|---|---|
| `trigger` | `impact`, `move`, `merge`, `recall` 중 허용 이벤트. 지속 작동을 추측하는 idle/use 이벤트는 없음 |
| `anchor` | `center`, `top`, `contact`, `wake`, 또는 물건 반너비·반높이를 기준으로 한 로컬 `{x,y}`. 로컬 좌표는 물건과 함께 회전 |
| `motion` | `scatter` 흩어짐, `rise` 상승, `pulse` 제자리에서 퍼짐, `orbit` 공간 안의 궤도 이동 |
| `directionMode` | `radial`, `up`, `opposite-motion`, 또는 물건과 함께 회전하는 로컬 `{x,y}` |

`trail`, `origin`, `direction` 설정은 위 속성으로 대체했다. 도형과 종류는 별개이며 같은 고리 도형도 스피커는 파문, 비행접시는 궤도 운동을 사용한다. 촛불 심지는 로컬 `(0,0.85)`, 로켓 추진구는 `(0.55,-0.65)`에 두었다. 로켓의 추진 방향은 이동 뒤편을 추정하던 방식에서 원본 그림의 추진구 방향으로 변경했다.

앵커·운동 모델은 낙하/착지 입자에 적용한다. 합성 공개는 정해진 공개 위치, 회수는 기존 손으로 이동하는 게임 궤적을 유지하고, 장식 입자의 허용 여부는 각 이벤트 trigger를 따른다. 복합 효과를 새로 조합하는 secondaryEffect는 이번 범위에 포함하지 않는다.

의미 기준 변경: 씨앗은 낟알 색, 햇빛은 빛무리, 알람시계는 음파로 변경했다. 크리스털은 보라색 반사광으로, 반지·메달·트로피 등은 지속 마법 방출 없이 짧은 반사광으로 바꿨다. 이 판단을 별도 fixture에 명시하고 자동 재생성하지 않는다.

## 보관소 분위기 조정

185종의 의미 분류를 유지하되 평상시 이동 입자는 끄고 충돌·합성·회수에만 반응한다. 일반 입자는 최대 4개·0.65초, 마법 물건은 최대 7개·0.85초를 기준으로 줄였다. 합성의 공통 접점 먼지와 4·5재료 축하 확산은 별도다. 전자기기 픽셀, 밀폐 용기·등껍질·가전제품의 고리는 작은 접촉 먼지로 교체했다. 금속과 비마법 반사광은 짧은 표면 반짝임이며 불꽃처럼 날리지 않는다. 천·고무의 반응은 작은 먼지와 기존 탄성·그림자로 표현한다. 별 입자는 마법봉·날개 마법봉·마법책·별가루에만, 보라 기운은 거울 속 마법문에만 사용한다. 입자 재질은 무광 중심이며 금속 입자·솔잎의 자체 발광과 충돌 섬광을 없앴다. 회수 흔적은 일반 4개·마법 8개로 제한했다.
