# 1대1 대전 — 중계 서버

대전은 받침대 하나를 함께 쓰는 판이고, **중계 서버를 거쳐** 붙는다.

```bash
pnpm relay:dev                                    # 로컬 중계 (localhost:8787, wrangler를 그때 받아온다)
VITE_RELAY_URL=ws://localhost:8787 pnpm dev       # 앱이 그 중계를 쓰게 한다

pnpm relay:deploy                                 # Cloudflare에 올린다 (wrangler login 필요)
```

## 왜 P2P를 지웠나

처음에는 WebRTC로 직접 붙였는데, NAT을 통과해야만 동작하는 구조라 같은 Wi-Fi의 두 기기조차 못 붙는 경우가 있었다 — 공유기가 멀티캐스트를 막으면 Chrome이 가려둔 mDNS 후보를 상대가 풀지 못하고, 같은 공인 IP 뒤라 헤어핀 NAT까지 필요하다. 그 구멍을 메우는 TURN은 공용 무료 서버가 더 이상 없다(peerjs·openrelay 모두 사라졌고, 각각 몇 시간씩 원인을 찾은 뒤에야 알았다).

중계는 그 조건을 통째로 없앤다. 양쪽 모두 **바깥으로 나가는 WebSocket 하나**만 열면 되고 그건 어떤 망에서도 열린다. 그래서 **P2P 경로는 남겨두지 않고 지웠다** — 어차피 붙지 않는 길을 대비책으로 두면 실패했을 때 "중계가 죽은 것"과 "P2P로 떨어진 것"을 구분하느라 시간만 쓴다.

## 중계 주소는 소스에 적혀 있다

비밀이 아니라서 — 어차피 클라이언트 번들에 실려 나간다 — 숨기지 않는다. 빌드 설정에 숨겨두면 저장소를 새로 받은 사람이 "왜 대전이 안 되지"를 코드에서 찾을 수 없다.

## 방 하나가 Durable Object 하나다

`worker/`에 있다. 같은 코드는 언제나 같은 인스턴스로 가므로 방을 찾는 절차가 필요 없고, 전송로는 `Transport` 인터페이스 뒤에 있어 게임 코드는 무엇으로 붙었는지 모른다 — 그래서 시험용 루프백으로 갈아끼워 서버 없이도 판 전체를 자동 검증한다.
