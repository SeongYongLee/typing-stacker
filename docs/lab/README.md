# 게임 개선 실험실

2026-09-13 시작. 작업 브랜치: `codex/gameplay-lab`.
기존 작업 폴더와 main을 유지하고 별도 워크트리에서 개선한다.

## 판단 기준

“세계에서 가장 재미있는 게임”은 자동 테스트로 판정하지 않는다.
자동 검증은 오류·진행 막힘·선택 기회·난이도를 확인하고, 재미는 실제 플레이에서 확인한다.
각 변경은 가설 → 최소 구현 → 관련 테스트 → PC/모바일 확인 → 채택/보류 기록 순서로 진행한다.
회수량만 늘고 합성이 줄어드는 변경은 성공으로 취급하지 않는다.

- 안정성: 관련 테스트와 타입 검사 통과, UI 변경은 PC/모바일 경계 크기 확인.
- 게임 흐름: 첫 성공까지 시간, 합성/분, 회수/분, 생존 시간과 진행 불가 비율을 함께 비교.
- 실험: 동일 seed 대조군을 보존하고, 채택 후보만 별도 seed로 재검증.
- 재미: 실제 플레이의 선택 이유, 실패 원인 이해, 재도전 의사를 기록. 미실시를 통과로 쓰지 않는다.
- 변경은 작은 커밋으로 남긴다. main 병합·배포는 별도 요청 때 진행한다.

## 실행과 재개

`pnpm install --frozen-lockfile` 후 `pnpm dev --host 0.0.0.0 --port 5176 --strictPort`.
워크트리에는 잠금 파일 기준으로 의존성을 별도 설치했다. 원격에서도 위 설치 명령을 실행한다.
검증: `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`.
UI 검사 스크립트의 주소/브라우저 실행 경로는 실행 환경에 맞춰 확인한다.
재개할 때 이 문서, `BACKLOG.md`, `CHANGELOG.md`, 기존 `../measurements/` 판단 기록을 읽는다.
완료된 실험을 반복하지 않고 다음 미완료 항목 하나를 수행한다.

## 맥북을 닫은 뒤의 실행

현재 원격 작업은 시작되지 않았다. CLI는 ChatGPT 로그인 상태이지만 연결된 Cloud 환경 목록이 비어 있다.
로컬 터미널이나 caffeinate만으로 덮개를 닫은 상태의 실행을 보장할 수 없다.
Codex Cloud 환경 설정에서 이 저장소를 연결한 뒤 실험 브랜치를 선택해야 한다.
환경 준비 후 `REMOTE_TASK.md`의 지시를 원격 작업에 전달한다.
Cloud 작업 하나는 유한한 작업이며 무기한 자동 재시작을 뜻하지 않는다.

공식 안내: https://learn.chatgpt.com/docs/cloud
환경 설정: https://chatgpt.com/codex/settings/environments
