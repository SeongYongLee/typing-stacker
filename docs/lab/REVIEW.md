# 현재 플레이 버전 검토

2026-09-13. 브랜치 codex/gameplay-lab, 기능 기준 커밋 fd80428.
PC: http://127.0.0.1:5176/ . 모바일은 같은 Wi-Fi에서 개발 서버의 Network 주소로 접속한다.
로컬 서버이므로 맥북 절전 후 접속/작업 지속은 보장하지 않는다.

## 실제 적용한 변경

- 모든 메뉴 버튼 규칙 통일, 순위표 모달 및 모바일 동작 정리(이전 작업 보존).
- 첫 단계 회수 목표10 유지, 경보 반입10 유지.
- 회수 입력도 타자 속도에 포함.
- 자연 합성 성공 때 경보를 최대15 낮추고 PC/모바일에 실제 감소량 표시.
- 결과 화면에서 회수 횟수를 먼저 표시하고 다음 판 행동 안내.
- 타자 정확도로 오해할 수 있던 비율을 실제 놓침 감점으로 표시. 점수 산식 유지.

## 보류한 후보

- 2단계 회수 목표28→18: 완료 증가 부족.
- 공급 보정 및 내부 합성 계획을 요청에 연결: 효과 부족 또는 합성 감소.
- 실제 재료 기반 요청: 회수는 늘었지만 새 seed slow 합성 유지77.9%.
- 점수 산식 변경: 입력 지표 정의와 기존 순위 비교 문제부터 결정 필요.

## 사람이 확인해야 하는 것

PC와 모바일에서 각각 한 판 이상 플레이하고 아래 질문에 짧게 답한다.

1. 첫 합성/회수에서 무엇을 입력하거나 어디에 놓을지 알 수 있었는가? 헷갈린 순간의 물건 이름도 기록한다.
2. 경보가 찼을 때 합성으로 낮추겠다는 선택을 했는가, 우연한 보상처럼 보였는가?
3. 끝난 이유와 다음 판에 바꿀 행동이 떠올랐는가? 바로 다시 하고 싶은가, 여기서 그만하고 싶은가? 이유는 무엇인가?

답이 나쁠 때 다음 수정 방향:
- 요청/낙하 단어 혼동 → 입력 대상 구분 및 안내 위치 조정.
- 합성 재료 선택 불명확 → 발견한 레시피를 떠올릴 수 있는 힌트 검토.
- 경보 회복을 못 느낌 → 보상 표시와 타이밍 개선. 수치부터 키우지 않는다.
- 불가피한 이탈처럼 느낌 → 이탈 직전 상태와 조준·회수 기회를 조사.
- 다음 단계 대기 → 목표 추가 축소보다 요청/재료 공급과 행동 선택 확인.
