# 회수 흐름 비교 계획

2026-09-13. 결과를 읽기 전에 고정한 1차 자동 평가 기준.

- 변경 전/후 동일한 초기 시드 12개 × 입력 정책 2개, 판당 최대 180초.
- 봇은 회수 가능한 첫 요청을 우선 처리하고, 아니면 중앙 근처에서 가장 오래된 단어를 입력한다. 물리를 변경하거나 물건을 지급하지 않는다.
- steady: 기본 입력 간격 0.9초 + 글자당 0.08초, slow: 1.8초 + 글자당 0.22초. 실제 초보·숙련자 표본을 대신하지 않는다. 오타와 레시피 계획은 모델링하지 않는다.
- 단어 공급 변경은 이후 난수 소비와 물리 결과도 바꾼다. 같은 시드는 출발 조건을 맞출 뿐 동일한 물건 궤적을 보장하지 않는다.

잠정 채택 조건(두 정책 각각): 회수 불가능 시간 비율 15% 이상 상대 감소, 플레이 시간당 회수 20% 이상 증가, 입력 드롭당 고유 단어 수가 기존의 80% 이상, 평균 생존 시간이 기존의 90% 이상. 첫 회수 시간은 보조 지표로, 회수 없이 끝난 판을 제외해서 좋아 보이게 만들지 않는다. 미회수 판 수도 반드시 보고한다. 전체 기준 통과도 재미 검증이 아니라 제한된 봇 정책에서의 개선 근거다.

조건이 실패하면 원인을 분석한다. 추가 조정은 탐색 실험으로 명시하고 새로운 시드에서도 확인한다. 개선되지 않으면 채택하지 않는다. 이후 난이도·보상은 공급 변경을 확정한 뒤 각각 별도 비교하며, 검증하지 않은 단계는 보류로 판단한다.

실행: `MEASURE=1 MEASURE_FLOW=1 FLOW_LABEL=baseline FLOW_OUTPUT=docs/measurements/flow-baseline.json pnpm exec vitest run tests/measure/whiteboard-flow.measure.test.ts`

## 후속 탐색 실험

1차 후보는 두 정책 모두에서 합성 횟수가 감소했으며 모든 사전 조건을 만족하지 못했다. 따라서 즉시 채택하지 않고 목표 구성만 변경/공급만 변경을 분리했다. 이것은 사후 원인 탐색이며 별도 확증 실험이 아니다. 원래 조건을 완화해서 통과로 처리하지 않는다.

추가로 공급은 원래 규칙을 유지한 채 첫 단계 목표 10회, 경보 반입 5개를 각각 시험한다. 목표 실험은 첫 단계 완료 판 비율이 25%p 이상 늘고 생존 시간이 기존의 90% 이상인지 본다. 합성/분도 같이 보고하며 20% 넘게 감소하면 채택을 보류한다. 경보 실험은 3.2초+글자당 0.35초의 pressure 정책으로 단어 만료가 발생하게 하며, 경보 발생 표본과 생존·회수 결과를 확인한다. 경보 후 플레이어가 회복 선택을 했는지는 이 봇으로 검증할 수 없다.
