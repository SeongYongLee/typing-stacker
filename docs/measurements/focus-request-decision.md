# 현재 합성품을 회수 요청에 연결: 단순 연결 후보는 보류

2026-09-13. 첫 단계 목표 10회, 경보 10개를 고정하고 12개 초기 시드 × 두 입력 정책 × 대조/후보 총 48판을 비교했다. 경보는 실제 설정에서도 이미 10개이므로 변경할 것이 없었다.

|정책|회수/분 기존→연결|합성/분 기존→연결|첫 단계 합성/분 기존→연결|
|---|---:|---:|---:|
|steady|3.84→3.77|3.01→2.94|3.48→3.45|
|slow|3.29→3.25|3.35→3.36|3.72→3.72|

합성 경험은 대체로 유지했지만 회수/분 증가 기준(+15%)은 두 정책 모두 실패했다. 따라서 이 후보를 본 게임에 적용하지 않았다. 실패한 후보를 검증 시드에서 반복해 유리한 결과를 찾지 않는다.

검증한 것은 ‘실제 공급된 재료의 내부 집중 레시피 결과를 한 요청 칸에 넣고 최소 30초 유지하는 방식’이다. 내부 집중 레시피는 플레이어의 의도를 직접 나타내지 않는다. 30초 고정은 요청이 자주 바뀌는 문제를 피하지만 실제 물리 합성 시점과 어긋날 수 있다. 어느 요인이 지배적인지는 아직 추가 추적이 필요하다.

다음 후보를 만든다면 공급 예정 레시피만 보기보다 **현재 상자에 실제로 모인 재료와 접촉 가능성**을 보고 요청할 필요가 있다. 완성 직후에만 요청하면 ‘계획해서 만드는 재미’와는 다른 보상이 되므로 별도 안으로 구분한다. 이번 사용자의 모바일 메인 순위 버튼 검토를 먼저 진행하며 추가 후보 실험은 시작하지 않았다.

회수 가능한 요청 보호, 선택 단어 불변, 30초 유지 조건의 테스트 3개를 추가했다. `craftedRecalls` 기록은 합성으로도 얻을 수 있는 종류의 회수 횟수이며, 해당 개체가 실제 합성으로 생성되었다는 출처 판정은 아니다.
