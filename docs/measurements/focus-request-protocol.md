# 진행 중인 합성품을 회수 요청에 연결하는 실험

2026-09-13. 기준은 현재 잠정 설정인 첫 목표 10회·경보 10개다. 기존 목표 20회 결과와 비교하지 않는다.

- 변경은 테스트 전용으로, 화이트보드 한 칸에 실제 공급 중인 레시피의 결과를 요청한다.
- 주변 일반 단어를 공급할 때는 요청을 변경하지 않는다. 원래 단어 선택·난수·점수·회수량은 바꾸지 않는다.
- 연결한 요청은 적어도 30초 유지한다. 이미 회수 가능한 물건은 교체하지 않는다. 회수 후에는 다시 연결할 수 있다. 나머지 두 칸의 기본 요청 규칙은 유지한다.
- 먼저 같은 초기 시드 12개 × 두 입력 정책 × 두 버전을 비교한다. 통과 후보는 다른 시드에서도 확인한다.
- 사전 기준: 두 정책 각각 회수/분 15% 이상 증가, 전체 합성/분 및 첫 단계 합성/분이 기존의 90% 이상, 평균 생존/관찰 시간이 기존의 90% 이상. 회수 가능한 요청이 없는 시간과 합성 가능한 종류의 회수 수는 보조 지표다.
- 현재 봇은 새 요청을 보고 합성 배치를 계획하지 않는다. 입력 공급에 반응하고 회수 가능해지면 회수하는 고정 정책이다. 요청의 이해도·계획하는 재미는 인간 확인이 필요하다.
- 첫 단계 지표를 따로 기록해, 빨리 다음 단계로 넘어간 영향과 합성 경험 손실을 구별한다. 완전한 인과 분리는 아니며 결과로 전체 재미를 단정하지 않는다.
