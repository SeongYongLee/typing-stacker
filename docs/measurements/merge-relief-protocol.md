# 합성 시 경보 완화 — 사전 기준

후보: 실제 합성 1회마다 아직 차지 않은 경보 게이지15 감소. 이미 시작한 반입은 취소하지 않는다.
튜토리얼 제외, 기본 반입10개 유지. 요청·공급·물리 크기·점수는 유지. 시험 전용 구현.
기존 보상은 점수·발견이고, 입력 성공은 경보2~4 감소한다. 합성 완화는 합성을 통해 위기를 늦추는 가설이다.

1차는 압박 봇(pressure) 12seed 대조군goal-10 vs후보merge-relief, 최대180초.
경보 횟수/활동분 10% 이상 감소, 관측 생존시간90% 이상, 회수·합성/활동분80% 이상 유지해야 다음 검증.
첫 기준 미달은 보류, 충족하면 steady/slow 및 별도 pressure seed로 부작용 검증.
봇은 보상을 보고 전략을 바꾸지 않으므로, 이 실험은 생존/흐름 부작용 검사이며 재미 증명은 아니다.
