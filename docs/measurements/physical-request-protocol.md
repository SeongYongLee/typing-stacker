# 실제 재료 기반 회수 요청 — 사전 기준

대조군: 현재 목표10, 경보10, 기존 요청/공급 규칙.
후보: 새 단어 공급 시 게임판에 레시피의 모든 재료가 실제 존재하면 첫 요청을 결과물로 연결.
같은 재료를 두 개 요구하는 레시피는 수량도 확인. 단어 공급 자체는 바꾸지 않는다.
현재 회수 가능한 요청은 보존하고 연결된 요청은 30초 유지한다. 나머지 두 슬롯 유지.
이 구현은 시험 전용이다. 재료가 존재해도 서로 닿을 수 있는지는 별도 문제이며 플레이어 의도를 대변하지 않는다.

steady/slow 각 12 seed, 최대180초, 판마다 시계 초기화.
후보 채택 조건: 각 프로필 회수/분 15% 이상 증가, 합성/분 80% 이상 유지, 관측 생존 시간90% 이상.
첫 완료 수도 함께 기록. 기준 충족 시 offset104729 holdout을 진행한다.
기준 미달이면 보류하고 과거의 실패한 focus 후보와 같은 것으로 혼동하지 않는다.
