# 모바일 가독성 검증 — 2026-09-07

## 판정

**현재 카메라를 유지한 단순 세로 재배치는 채택하기 어렵다.** 단어는 읽을 수 있지만, 물건의 종류와 합성 위치를 구분하기에는 너무 작다.
이는 자동 브라우저 측정과 캡처 육안 검토의 결과이며, 실제 휴대폰 사용성 테스트 결과는 아니다.

## 재현

`pnpm dev` 실행 후 `/?mobile-readability=1`을 연다. 개발 모드에서만 열리는 비교 화면이다.
화면 크기, 키보드 예약 높이, 단어 4/10개, 낮/밤, 조준점 움직임을 바꿀 수 있다.

- 실제 게임의 글꼴·그림·ArenaRenderer를 사용한다. 물건 위치는 고정 fixture다.
- 모바일 안은 단어를 20px 글꼴의 2열 목록으로 모으고, 회수 목록과 입력 영역을 별도로 배치한다.
- 기본 가정: 브라우저 UI 64px, 키보드 320px. CSS 픽셀 기준이다.
- 키보드는 면적만 예약한다. OS 키보드, 실제 입력, 물리 진행, 낙하 단어의 움직임은 구현하지 않았다.
- 4개는 비교용 장면이며 10개는 코드상 동시 단어 상한을 채운 스트레스 장면이다. 10개가 항상 나온다는 의미는 아니다.
- 계란 높이는 실제 variant의 artBounds와 렌더러 배율을 곱한 그림 경계 높이다.

## 측정 결과

| 화면 | 게임 가시 높이 | 단어 4개: 아레나 높이 | 계란 높이 | 단어 10개: 아레나 높이 | 계란 높이 |
|---|---:|---:|---:|---:|---:|
| 360 × 740 | 356px | 131px | 6.0px | 11px | 0.5px |
| 390 × 844 | 460px | 235px | 10.8px | 115px | 5.3px |
| 430 × 932 | 548px | 323px | 14.8px | 203px | 9.3px |

390 × 844, 단어 4개에서 키보드 예약 높이를 바꾸면:

| 키보드 공간 | 아레나 높이 | 계란 높이 |
|---|---:|---:|
| 280px | 275px | 12.6px |
| 320px | 235px | 10.8px |
| 360px | 195px | 8.9px |
| 0px (비교 기준) | 555px | 24.4px |

키보드를 없앤 비교에서는 물건 크기가 개선된다. 병목은 화면 폭만이 아니라 가용 높이다.
기존 3열을 390px 폭에 맞춘 비교에서는 단어 글꼴이 11.4px이고 긴 단어가 왼쪽 화면 밖으로 나간다.
이 비교는 레인과 아레나 영역의 실험이며 전체 기존 게임 UI를 축소한 캡처는 아니다.

## 육안 확인

- 20px 단어는 긴 이름도 읽을 수 있었다. 측정한 목록 카드의 가로 넘침은 없었다.
- 조준 화살표는 선명하지만 상자와 물건은 아래쪽에 작게 모인다. 물건 종류와 맞닿는 위치를 읽기 어렵다.
- 낮과 밤 모두 물건 크기가 병목이다. 배경의 큰 화이트보드는 모바일의 별도 회수 목록과 중복돼 시선을 분산한다.
- 작은 화면에서 단어 10개는 아레나를 사실상 없앤다. 목록 높이를 단어 수에 따라 무제한 늘릴 수 없다.
- 움직이는 조준점은 확인했지만, 타이핑하면서 타이밍을 맞출 수 있는지는 아직 확인하지 못했다.

## 다음 시제품에서 바꿀 것

1. **모바일 카메라:** 상자와 탑 주변을 확대하고, 긴 낙하 경로를 전부 보여줄 필요가 있는지 검증한다. 화면 밖 스폰 위치와 조준 안내를 분리하되 실제 착지 x좌표를 정확히 표시한다.
2. **단어 표시:** 영역 높이를 제한하면서 현재 제출 가능한 단어와 남은 시간을 모두 읽게 한다. 단어를 숨기거나 밀도를 낮추는 방법은 게임 규칙 변경이므로 별도 결정한다.
3. **배경과 HUD:** 큰 장식 화이트보드와 중복 정보를 줄이고 회수·혼잡·점수 정보를 압축한다.
4. 위 변경에서도 작은 화면이 충분하지 않으면 지원 최소 높이 또는 모바일 규칙 조정을 검토한다.

물건의 작은 쪽을 약 24px 이상으로 읽을 수 있는 것을 시제품의 초기 목표로 둔다. 이는 프로젝트 기존 가독성 기준을 참고한 목표이며 보편적 사용성 기준은 아니다.
확대 시 탑 성장, 화면 밖 낙하·이탈, 회수·합성 연출이 가려지지 않는지 추가 검증한다.
