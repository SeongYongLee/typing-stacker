# 상자 확대 시제품 — 2026-09-07

## 후속 수정

현재 적용: 상시 합성 히스토리를 제거했다. 합성 결과는 상단 점수·회수 수치 자리에서 2초만 표시하고 사라진다. 화이트보드·경보 게이지·일시정지 버튼은 계속 보인다. 해당 영역의 높이는 고정되어 알림 전후 게임판 배율과 위치가 바뀌지 않는다. 연속 합성 시 최신 결과 기준으로 표시 시간을 갱신한다.

점수·회수 수치와 경보를 44px 헤더로 묶고, 일반적인 단어 영역을 88px에서 64px로 줄였다. 390 × 780 창에서 키보드 320px를 예약했을 때 게임판은 128px에서 224px로 커졌다. 화이트보드에는 ‘입력하면 회수’ 제목, ‘회수 가능/상자에 없음’ 상태, 대응하는 단어 카드에는 회수 배지를 표시한다. 실제 회수 성공 피드백은 ‘계란 회수 완료 ✓’처럼 구분한다.

확인: 합성 알림 전·중·후 게임판 위치와 크기 동일, 2초 뒤 자동 닫힘, 연속 알림 타이머 갱신, 실제 엔진에 회수 대상을 배치한 검증에서 회수 가능 표시·배지·회수 완료 메시지 작동. [현재 배치](compact-ui.png), [합성 표시 중](transient-merge.png).

### 이전 변경 기록

이전 시제품에서는 움직이는 화살표를 복구하되 점선은 생략했다. 합성 효과는 게임판 위에서 입력창 위의 고정된 히스토리 영역으로 옮겼었다. 반짝임과 등장 애니메이션은 해당 영역 안에서만 재생되고, 최근 합성 4개를 옆으로 넘겨 확인할 수 있었다. [이전 화면](history-arrow.png).

- 모바일 조준 화살표와 화면 위 진입 아이콘을 제거했다. 확대된 화면 상단으로 실제 물건이 들어와 떨어진다.
- 낮/밤 배경을 복구했다.
- 합성 결과를 모바일 DOM 알림으로 표시한다. 결과 이름·그림·재료를 보여주고 긴 이름은 줄바꿈한다. 회수 목록도 줄바꿈하며 회수 가능한 단어를 강조한다.
- 상단 경보 게이지를 실제 혼잡도에 연결했다. 80% 이상과 경보 반입 중에는 붉은색으로 표시한다.
- 입력창 옆 놓기 버튼을 제거했다. 키보드 Enter와 네이티브 폼 제출이 같은 제출 경로를 사용하며 입력 포커스를 옮기지 않는다.
- 자동 브라우저에서 Enter·폼 제출의 연속 성공과 포커스 유지, 한글 조합 후 잔여 입력 정리, 실제 혼잡도 80% 반영을 확인했다. 실제 OS 키보드는 추가 확인이 필요하다.
- [배경·Enter 입력](enter-background.png), [합성·경보 표시](merge-gauge.png).

아래 크기 비교와 조준 안내는 이전 시제품의 기록이다. 현재 화면에는 경보 게이지와 회수 목록이 추가되어 실제 아레나 높이가 달라졌다. 짧은 화면에서는 물건 크기와 합성 알림의 공간이 여전히 부족할 수 있다.

## 결과

390 × 844, 브라우저 64px·키보드 320px 예약 조건에서 고정 장면의 계란 그림이 **10.8px → 24.4px**로 커졌다.
단어 영역을 116px로 고정했으므로 단어가 10개여도 아레나와 물건 크기는 같다.
낮은 화면에서는 여전히 부족하다. 360 × 740에서는 같은 조건의 계란이 9.3px이므로 모바일 전체 지원 완료로 판단하지 않는다.

| 화면 | 이전 4개 / 10개 | 확대 4개 / 10개 |
|---|---:|---:|
| 360 × 740 | 6.0 / 0.5px | 9.3 / 9.3px |
| 390 × 844 | 10.8 / 5.3px | 24.4 / 24.4px |
| 430 × 932 | 14.8 / 9.3px | 26.9 / 26.9px |

위 수치는 동일한 고정 장면 비교다. 실제 플레이는 탑 높이에 맞춰 배율이 바뀌므로 항상 같은 크기를 보장하지 않는다.
10개 장면에서는 단어 글꼴을 20px에서 17px로 줄인다. 이는 상한 스트레스 상황의 절충안이다.

## 바꾼 것

- 기존 렌더러에 명시적으로 켜는 확대 카메라를 추가했다. 기존 데스크톱·멀티플레이는 기본 카메라를 사용한다.
- 실제 스폰 높이, 조준 x좌표, 물리와 점수 규칙은 유지한다. 화면에는 상자와 탑 주변을 크게 보여준다.
- 조준 화살표를 탑 가까이 표시한다. 위쪽 화면 밖에서 내려오는 물건은 같은 x좌표에 진입 아이콘으로 알린다.
- 탑이 자라면 상자와 탑 꼭대기를 함께 볼 수 있도록 줌을 줄인다. 높은 탑에서는 다시 물건이 작아질 수 있다.
- 모바일 시제품에서는 큰 장식 배경을 단순하게 바꿔 작은 물건과 단어에 집중하게 했다.

## 직접 플레이

개발 서버에서 `/?mobile-play=1`을 연다. `입력하고 시작` → 단어 입력 → `놓기`를 누른다.
물리 키보드에서는 조합을 끝낸 뒤 Enter로도 제출할 수 있다. 기존 게임의 1단계를 튜토리얼 없이 시작한다.
일시정지·재개·게임 종료 후 재시작이 가능하다. 도감·랭킹 저장과 오디오는 연결하지 않은 연습용 시제품이다.

휴대폰에서는 실제 가시 영역에 맞춰 화면을 조절한다. 키보드·브라우저 UI의 영향을 받는 영역 측정에
[VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)를 사용한다.
입력 포커스를 잃거나 앱을 벗어나면 멈추며, 가시 높이가 320px 미만일 때도 일시정지한다.
화면 회전과 높이 변경 시 게임 엔진을 새로 만들지 않는다.

데스크톱에서 키보드 공간만 흉내 내려면 `/?mobile-play=1&keyboard=320`을 사용한다.
휴대폰에서는 `keyboard` 파라미터를 붙이지 않는다.

## 확인한 것과 남은 것

- 기존 렌더러를 사용하는 고정 장면에서 크기 비교 및 육안 확인.
- 실제 게임 엔진으로 4개 단어의 연속 제출과 성공 피드백, 물건 낙하 확인.
- 브라우저 자동화로 Enter 제출, 조합 후 잔여 입력 정리, 일시정지·재개 및 뷰포트 변경 확인.
- 카메라 테스트: 작은 물건 크기, 탑 성장 시 시야와 화살표 여백, 0 크기 전환 처리.
- 실제 iOS/Android 키보드와 조준 성공률은 사용자의 실기 플레이가 필요하다. 합성·회수·고양이 연출과 높은 탑은 추가 검증 대상이다.
